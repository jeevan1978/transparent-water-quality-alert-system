# Trained Machine Learning Models Directory

This directory stores serialized model artifacts generated by the project's training pipeline (`scripts/train_models.py`).

## Expected Artifacts
1. `current_classifier.joblib`:
   - Multi-class classifier (e.g. Random Forest or Gradient Boosting) trained to predict current water quality (`Good`, `Needs Treatment`, `Poor`) from water telemetry parameters (pH, Turbidity, Dissolved Oxygen, Temperature, Conductivity, Total Dissolved Solids).
2. `forecaster_6h.joblib`:
   - Multi-output or chained regressor forecasting key parameters 6 hours into the future.
3. `forecaster_24h.joblib`:
   - Regressor forecasting key parameters 24 hours into the future.
4. `scaler.joblib`:
   - StandardScaler or MinMaxScaler fitted during preprocessing.

## Policy on Legacy / External Models
- **Do NOT load or reuse** `water-model1.pkl` from the original repository without verifying pickle compatibility, dataset lineage, and GPL-3.0 obligations.
- All models here are trained on clearly labeled synthetic telemetry data.
