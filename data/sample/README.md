# Sample Data Directory

This folder contains simulated sample water quality datasets.

## IMPORTANT NOTICE & DISCLAIMER
- **100% Synthetic / Simulated Data**: All data in this directory is synthetically generated via `scripts/generate_data.py`.
- **Educational & Prototype Use Only**: This data does NOT reflect real-world measurements and **must not** be used to certify or verify drinking water safety or make public health decisions.
- Real water sensors would measure physical parameters such as pH, Turbidity, Dissolved Oxygen, Temperature, and Conductivity, but here they are simulated with diurnal sinusoidal waves, Gaussian noise, and occasional synthetic anomaly events (e.g., rainfall runoff or contamination events).
